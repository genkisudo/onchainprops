Privacy Policy

Onchain Props (onchainprops.xyz) is a static site. It has no accounts and no server of its own. The HTML does not set cookies. Data leaves the browser only through the scripts below, and only as those scripts are written.

Analytics

After the page has rendered, script.js loads Amplitude Analytics from amplitude.min.js. That file is the Amplitude browser SDK without session replay. The init call leaves Amplitude's other autocapture on, so Amplitude records page views, sessions, attribution and clicks. The same script also sends events for firm-list views, firm-card views, firm clicks, clicks on links to firm websites, FAQ opens and closes, resource-link opens, blog filters, newsletter signups and page errors.

The site does not set an identity-storage option, so Amplitude uses its default and stores a device identifier in a cookie. That cookie is how Amplitude recognizes the same browser on a later visit.

Email and chat

The newsletter form posts the email address you submit to Kit at app.kit.com. Nothing is sent unless you submit the form. Pages that include the chat widget load it from agents.dante-ai.com. Messages you type there are sent to Dante.

Third-party links

Links to prop firms, tools and other sites leave onchainprops.xyz. Some of those links are affiliate links. The other site has its own cookies and its own privacy policy. Onchain Props does not control that site.
